# Fogaren-OOI-Irminger
 Biological Pump in the Irminger Sea 


# CTDcasts_OOIcruises folder
 Kristen Fogaren 12/04/2020 
 Each *.mlx/*.m file shows CTD casts done in the vicinity of OOI Irminger Sea assets with a map of cast locations. 

 Workflow: 
  CTD files were downloaded from Alfresco (https://alfresco.oceanobservatories.org/alfresco/faces/jsp/browse/browse.jsp)
  Files were converted to *.cnv files using Seabird Software.
  Downloaded files and resultant *.cnv files are available here: 				https://drive.google.com/drive/folders/1v45V_swVJCeSSQPa-fFQ20w3vlAsP2rw?usp=sharing
  Python script (Process_CTDcnv_Files.ipynb) was used to process *.cnv files 
  Processed casts were output as *.csv files, stored as tables in Matlab, and saved as *.mat files for each year. 
  Saved *.csv and *.mat files are located here: 
	https://drive.google.com/drive/folders/1i712Jeq7wbouzS6vJcLvigj4TGbWqhSZ?usp=sharing
